# `docs/rules/`

- **Owner:** project owner only

## Role

Working rules for each developer role and its Claude Code agent.

## How it works

`FRONTEND.md` and `BACKEND.md` define the scope, allowed folders and rules for each role. The active role of a machine is set in `.claude/role.local` (see CLAUDE.md).

## Rules

- Every source file starts with a `Role:` header comment.
- Keep this README up to date when the folder content changes.
- See `ARCHITECTURE.md` and `docs/rules/` for the full rules.
